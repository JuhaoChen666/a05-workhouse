## 各阶段实现及用户可见行为

### P4/P5 实际业务闭环

经历库接入持久 PDF 上传/已有文件选择、批次及来源文件分页、失败原因和字段问题、草稿修正/删除/重试/取消及显式确认。未保存修正不能确认；确认前不产生正式经历，重复确认沿用回执，revision 冲突等返回真实错误。展示页码/原文片段，不暴露私有存储路径。排序调用服务端持久接口，编辑不丢失来源、归档与顺序信息。

手工模式按选择顺序使用原始经历，不调用 AI；AI 只允许使用冻结的用户经历。伪造 ID/原始 bullet/重复来源/新增数字拒绝，无法验证的语义改写保留原文并记录。AI 不可用按关键词明确降级，界面和结果 metadata 可识别，不伪装成 AI 成功。

新增个人信息和教育输入。两套新 **1.2.0 / 协议 1.1** 模板实际渲染模块顺序及中英标题；语言同时传入规划，事实正文保留原语言。页数定义为真实 PDF 上限，pypdf 验证超限时失败、给出处理建议、不保存成功文档。模板原 1.0/1.1 文件未覆盖；选择性初始化只发布新版本，旧模板原始字节与历史快照保持不可变。

### P6 简历库与历史兼容

新增 owner 隔离的文档列表、详情、命名、复制、软删除和 PDF/LaTeX 下载，统一使用 **document_id**；共享生成任务的副本独立管理，原文档删除不影响有效副本输出。

展示 JD、模板版本、经历与个人/教育快照。再次编辑用原冻结快照初始化，可调整 JD、个人/教育、原快照经历选择及支持的选项，创建新任务/新文档；经历或模板后来改变不覆盖旧事实和输出。

旧优化记录显式 `format=markdown`、owner 隔离只读；用户主动重新生成先创建私有持久草稿，经 AI 抽取、用户修正和确认后进入新生成流程。保留历史正文，不批量迁移。管理、主页和帮助的主入口指向 LaTeX，新内容不经 Markdown/HTML 排版中间层；旧页面保留历史兼容。

### 编译隔离、持久任务与 P7

API 仅入库 PENDING，不依赖 BackgroundTasks 执行生成。worker 用独立 MySQL 连接持有任务锁和数据库范围全局容量锁，执行 token 再次检查最终提交；避免同一任务重复执行和并发重复文档。重启后明确将孤儿 PROCESSING 标为中断，用户重试沿用冻结输入。真实 worker 子进程终止、第二进程恢复判定和再次生成的测试通过。

Docker 编译仅接受可信不可变镜像；检查 Linux/cgroup/内存/swap/CPU/PID/seccomp 能力，非 root、无网络、只读、最小环境、限制资源和输出。无必需能力明确失败，不回退宿主；超时仅清理 ID 与标签匹配本任务的容器。镜像 Dockerfile 和固定编译入口已准备，**目标容器未构建或实测**。

API、worker、模板初始化和保留期维护统一显式 DATABASE_URL/私有文件配置；提供不依赖旧面试 AI/RAG 的简历专用 API 入口。owner 隔离指标包含任务耗时、失败类型、AI 成功/降级、导入 AI 调用/失败、重试、队列积压与最长未完成时长。worker 日志仅含任务身份、耗时、状态及错误码，无完整经历和秘密。维护默认 dry-run，文档给出部署配置、迁移及守护回退约束。

# AI 面试平台 - 管理后台

独立后台管理系统，与主站共用后端 API（`http://localhost:3000/api`）。

## 功能

- **登录**：使用与主站相同的账号，管理员角色（roleId=2）可访问全部功能
- **用户管理**：查看用户列表（仅管理员）
- **岗位管理**：岗位的增删改
- **题库管理**：题目列表、按岗位筛选、增删改
- **学习资源**：资源列表、增删改

## 开发

```bash
cd sc/admin
npm install
npm run dev
```

默认运行在 **http://localhost:5174**（与主站 5173 错开）。

## 构建

```bash
npm run build
```

## 说明

- 需先启动后端：在 `sc/backend` 下执行 `npm run dev`
- 管理员账号需在数据库中将其 `role_id` 设为 2（角色表里 2=管理员）
